# Reconstructed BTU skill stamps

These SVGs are reconstructed presentation assets for the OrionX landing-page
animation. They are not original vector masters supplied by BTU.

Reference: the three PNGs in `packages/core/assets/btu/skills`, supplied through
the BTU Visual Reference Drive folder recorded in the adjacent asset manifest.
The triangle, rectangle, circle, wording, colors, and layout follow those stamps.
Typography has been reconstructed with Nimbus Sans Bold and URW Gothic Book,
then converted to paths. Every visible element is vector geometry; these files
contain no embedded bitmap, external fonts, scripts, or remote resources.

The original PNGs and existing WebPs remain available for archival comparison
and issued passport rendering. Only the new homepage illustration uses these
reconstructions.
